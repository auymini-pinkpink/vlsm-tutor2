📚 Variable Length Subnet Masking (VLSM) Guide

VLSM allows you to allocate IP addresses efficiently by applying different subnet masks to individual subnets based on host demands.

1

Sort Requirements

Arrange your required host sizes from largest to smallest. Large requests dictate the base block alignment.

2

Find Block Size

Add 2 (for Network & Broadcast addresses) to the needed host count, then round up to the nearest power of 2 ($2^n$).

3

Determine Prefix (/CIDR)

Calculate host bits needed ($n$). Subtract from 32 to get your mask ($32 - n$). Example: 100 hosts requires 128 block ($2^7$), prefix is $/25$.

4

Assign Next Network ID

Start the next subnet at the previous Broadcast address + 1.
