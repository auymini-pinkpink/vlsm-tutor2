# VLSM Tutor

A simple, mobile-friendly **VLSM learning tool** you can deploy as a static website (GitHub Pages, Netlify, Vercel).

## Features

- 🧮 VLSM calculator (base network + host requirements)
- 📚 Step-by-step “Teach Me” explanations
- 🎯 Practice questions with instant feedback
- ✅ Answers + explanations stored in the browser (`localStorage`)
- 🧠 CIDR / subnetting quick reference
- 📊 Network / first usable / last usable / broadcast calculations
- 📱 Mobile-friendly layout
- 🌙 Dark/light theme toggle
- 🚫 No backend required
